# Session-bound SDL handoff — PGF3

The selected owner contract requires every design-changing assignment to use SDL
WORK, separately assess Blueprint need, preserve exact design disposition and prevent
whole-assignment closure before the accepted model is released. PGF2-C1c supplies
host execution but does not remove the existing no-design-only Session guard.

## Ownership decision

Keep the registered Session and selected assessment as the workflow owner. Reuse
ModelGovernance snapshots/validation and the retained Blueprint catalogue as source
providers. A checked handoff must retain the exact Session/step/assessment, WORK
identity/head/live digest, model entrypoint, task and owned/protected code paths,
Blueprint requirement and any selected retained revision. Actual owner disposition
names that exact review basis; the privileged leader cannot manufacture it.

Do not activate an independent standalone prepared assignment and then retroactively
attach it to a Session. That creates competing scope claims and generation owners:
Session record publication would change the inputs of the independent approval.
Do not remove the no-design guard on the strength of file existence or an agent's
statement that the model is ready. Model snapshots prove source identity, and SDL
validation proves supported structural semantics; neither supplies owner approval.

The first adapter boundary is a read-only, current-source inspection. It returns
revision pins and explicit holds; it does not write records, create WORK, generate an
unrequested Blueprint, accept design, dispatch a host or release a model. Repeated
inspection must revalidate source bytes and preserve pending model-operation holds.
Expose the existing ModelGovernance semantic validator through a read-only API so
inspection and frozen artifacts use the same supported SDL/SDUI rules.

Subsequent mutation consumes an exact inspected basis through the existing canonical
Session effects machinery. Keep the design decision separate from the design-impact
assessment and from final code/owner acceptance. Changed WORK, task, Blueprint,
Session scope or protected boundaries holds dependent start/continuation. Historical
snapshots remain history rather than becoming retrospectively invalid.

At disposition, inspect the actual released artifact and its ancestry against the
reviewed implementation target. A matching filename or copied source digest without
provenance is insufficient. Required code tests/review and any actual owner gate remain
independent. Interrupted model promotion stays a recoverable model operation, never
an inferred successful release. Compatible WORK integration uses existing merge
ancestry and combined semantic validation before refreshing the affected handoff.

This contract refines the existing ModelGateAdapter responsibility. It does not
select a new SDL profile, runtime snapshots, code extraction or Blueprint redesign.
