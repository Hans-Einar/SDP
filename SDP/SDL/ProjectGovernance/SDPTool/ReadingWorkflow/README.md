# Producer-owned reading concern

Activity3 owns this bounded SDPTool/SDL collaboration concern. InventoryNavigation
is an observed architectural baseline, not a complete model of the existing tools.
ReadableNavigation defines the selected responsibility boundary and collection
reading workflow. ExternalXfmd is a collaborating caller, not a deployed part of
SDPTool. Libraries remain units inside SdpToolHost.

The Activity3 ImplementationContract and canonical HEOS NavigationDesign specify
query, source membership, page rules, error handling and acceptance. Work checkpoints
are preliminary design handoffs, not accepted model releases or runtime evidence.
