# Activity directory guide

This directory gathers documents for one change effort. Read
[01-Mandate/Mandate.md](01-Mandate/Mandate.md) for its need, scope and desired outcome.
[activity.yaml](activity.yaml) contains identity and references. Lifecycle state and
history are held in the project's canonical management ledger.

## 01-Mandate

The need mandate, desired outcome, constraints and scope decisions.

## 02-Study

Investigations, observations, alternatives and links to prior studies.

## 03-Requirements

Change requirements and references to authoritative system requirements.

## 04-Design

Architecture/design decisions and references to system-owned SDL models and
retained Blueprints. Current model sources remain in their canonical homes.

## 05-Implementation

The implementation plan or a pointer to its authoritative existing location.
Plans own milestones and acceptance criteria.

## 06-Verification

Acceptance criteria, verification records and evidence with candidate provenance.

## Sessions

Working Session logs covering any phase. Sessions link the selected plan/steps and
record outcomes and handoffs without duplicating the implementation plan.
