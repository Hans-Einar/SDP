Strict parsing tests include duplicate/unknown/case-variant fields, size/depth,
UTF-8, trailing input, bad types, unknown operations and schema versions. Workflow
tests verify human/JSON parity, exact output envelopes, path context, stale revisions,
forged/missing principal refusal and unchanged history on retries/refusals. Broken
stdout reports failure without retrying a mutation. Request IDs are correlation,
not mutation authorization or deduplication keys.

The incomplete-stdin OS trial exposed that closing stdin did not reliably wake a
blocked read. The executable now selects signal cancellation around its owned input
read; the library retains caller-owned I/O lifetime. The final actual process test
waits for exit before closing the pipe, so it proves cancellation rather than EOF.
