## Implementation and integration seams

- Exact source 0.3 adds tree/list with required nonblank string label and optional
  symbolic callback, without changing 0.2 local acceptance or syntax-only behavior.
  One parser/normalizer handles both profiles. Unknown constructed Document profiles
  reject. The new EBNF/profile document specifies the source/export boundary.
- `parser.Instance.Profile string` is `sdui/0.3` on every 0.3 normalized node,
  including reused definitions. Empty is the legacy 0.2 sentinel. Its omission is
  narrowly handled in tagged Data and Go literal emission; other old fields retain
  their representation. No change to frozen fixtures or generated prerequisites.
- `parser.EffectiveProfile(root *parser.Instance) (string, error)` validates a
  bounded, nonnil, non-repeated tree and uniform profile; returns `sdui/0.2` for
  the empty sentinel or `sdui/0.3` for its explicit marker. Mixed/unknown profiles
  reject, including hidden descendants. This is profile validation, not complete
  widget/provider/native admission.
- `parser.ASTFormat(profile string) (string, error)` accepts only explicit
  `sdui/0.2` and `sdui/0.3`, returning their exact AST envelope formats. CLI uses
  this helper; validation values and envelope fields are retained.
- 0.3 generated constructors use `sdui-go-model/2`, `UIProfile`, `UIASTFormat`,
  existing source hash and Document/Root functions. 0.2 generated bytes remain
  identical to the committed repaired example. Generated code contains no providers.
- Text/Markdown/composition identify collections, instance paths, symbolic
  activation and absent provider data truthfully. Hidden unknown widget/node kinds
  reject rather than falling into SVG placeholders. Combined composition reuses
  its existing source-span/use-chain metadata and the checked Markdown path.
- `svg.Check(root *parser.Instance, options svg.Options) error` checks support
  before output; the CLI calls it before layout/resource preparation. Public SVG
  collections reject with `unsupported-collection-export`, exact path and original
  span, including hidden collections and when measured geometry is supplied.
- Native background omission requires `SkipControls: true` plus
  `NativeControls map[string]string` (normalized path -> prepared native kind).
  Every omitted button/input/tree/list must match the inventory; extra, missing or
  mismatched entries and unknown kinds reject. Inventory is a trusted host adapter
  assertion, not proof from a public flag. Noether owns filling it from actual
  prepared controls. Ordinary public exports cannot silently skip collections.

Helper signatures and SVG integration expectations were sent to main and directly
to runtime/layout/host owners. No other lane's files were edited.

## Exported Go API compatibility

Default successful public 0.2 AST, structural text/Markdown, SVG and generated-Go
outputs retain their prior representation. Existing snapshot tests and exact
generated-bundle comparisons pass. No native SkipControls compatibility fallback
is silently applied to public export.

The deliberate Go API behavior changes are:

- Legacy `svg.Render(..., svg.Options{SkipControls: true})` calls that omit native
  controls must now also supply `NativeControls` with every actual prepared control's
  exact normalized path and kind. This applies to 0.2 button/input backgrounds too,
  not just 0.3 collections. Missing/mismatched/extra inventory is an error. The
  host owner must migrate these calls; the previously permissive omission behavior
  is intentionally tightened. `SkipControls: false` remains the default public
  path and retains valid 0.2 output.
- Exporters now reject unsupported widget/node kinds, including hidden nodes,
  instead of silently omitting them or treating them as SVG placeholders. These
  are invalid/unsupported models, not formerly valid source-profile controls.
- `parser.Validate`/Normalize now reject an empty or unknown constructed
  Document.Profile. Constructed Documents must explicitly choose `sdui/0.2` or
  `sdui/0.3`; only Instance.Profile has the legacy empty sentinel. Parsed 0.2
  Documents already carried the explicit profile.
- `parser.Instance` gains Profile and `svg.Options` gains NativeControls. Keyed
  Go struct literals can omit the new fields; external positional/unkeyed literals
  require migration for the added fields. Instance.Profile empty remains valid
  for legacy normalized models and is omitted from JSON and generated literals.
- ASTFormat, EffectiveProfile, svg.Check and codegen.Version03 are additive APIs.
  codegen.Version stays `sdui-go-model/1`; Generate selects `/2` only for explicit
  0.3 source. No runtime/host behavior compatibility is claimed by this lane.

The current 0.3 development profile includes only the authorized WCI1 additions.
WCI2 may later extend that same development profile only after the WCI1 pilot/review
and explicit authorization of its grammar. No future-family syntax is accepted
or implemented by this lane.
