## Runner inventory and supported boundaries

Exact planned selection: previews 5; collections 2; panes 2; commands 5; values 5;
text 7; helper 1 = 27. Prefix `nonmodal-` is converted by the runner to the original
variant plus `--nonmodal`. Pane split receives no `--vertical`; its vertical proof
is intentionally a reuse item. The runner sets `FYNE_THEME=light` and display :191.

- Connected .3 execution uses the staged SDL/DocumentHost applications with real
  providers/bindings. Legacy standalone RuntimeView and XFMD helper Launch do not
  acquire the new .3 adapters merely because discovery/static output accepts them.
- Direct closed-subset SVG and supported Markdown prose require positive native
  output. Unsupported native Mermaid resolves label/reject before gates, preserves
  surrounding prose and advertises no rendered Mermaid capability.
- Mounted Fyne Accessible descriptions/status must be observed independently of
  captions. Linux OS screen-reader delivery is not supported/proved; no other-OS
  accessibility bridge is claimed.
- Actual native acceptance is the explicitly selected **light theme**. Dark/system
  contrast and broader Go-Regular glyph/wrapping fidelity remain KB004. This is a
  declared evidence boundary, not a claim that every theme renders acceptably.
- X11/Xvfb/configured IBus proof does not establish Wayland, all IMEs, decorations,
  immediate GPU memory disposal, publication, installed XFMD upgrade or release.
