# Historisk bootstrap — ikke installasjonskilder

Tidligere rotkopier av payload, skills, kompatibilitetsinstaller og dokumentguide.
De avviker fra Toolkit-versjonene og beholdes som historisk materiale; de skal
ikke installeres, aktiveres som instruksjoner eller behandles som aktuelle maler.
Kildeinventar og oppdateringsregler eies av Toolkit/SDP-install.manifest.json.
R1 flyttet disse filene byteuendret. Git og R1s flyttematrise bevarer gamle adresser.
