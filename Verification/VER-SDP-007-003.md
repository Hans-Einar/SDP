### Medium

#### F01 — Revision 2+ can omit or fabricate the durable prior assignment chain

**Locations:** `SDP-vnext-pilot/ConcurrentAssignments.md`, reservation/refreeze
protocol; `SDP-vnext-pilot/IssueContract.md`, assignment mirror;
`SDP-vnext-pilot/WorkflowContract.md`, identity/revision rules; and
`SDP-vnext-pilot/validate_pilot.py`, `validate_assignment_history` around lines
1,654-1,725 plus the hard-coded Issue #7 checks around lines 2,066-2,124.

The contract says a changed assignment increments revision, links a durable
prior snapshot, records the exact prior source candidate/digest, and refreezes
with a reason. The generic history validator checks a chain only when at least
one of `previousRevision` or `refreeze` is already present. If both are absent,
it skips the assignment regardless of `revision`.

Changing the complete simple positive assignment from revision 1 to revision
2, with no other change and no history, returned no diagnostics. A second
probe supplied mutually consistent `previousRevision`, `refreeze`, and embedded
history values, but used a nonexistent snapshot path and fabricated 40-hex Git
candidate; that also returned no diagnostics. Local path and Git-object
resolution exist only in the filename-specific Issue #7 driver checks.

The current dogfood is not affected: its snapshot exists, its historical Git
blob reconstructs exactly, and all current/prior fields agree. The false
negative is nevertheless material to the first HSX pilot because its first
stale-base refreeze could receive a green generic validator result without any
recoverable prior assignment contract.

Required rework: require every typed assignment with `revision > 1` to carry
both `previousRevision` and `refreeze`, with exactly one matching immediate
prior snapshot; reject those fields on an unsupported revision-1 reuse. At the
repository driver boundary, resolve every local snapshot path and source Git
candidate generically rather than only `ISSUE-007`, and compare the historical
assignment's Issue/source/revision/reservation contract. Add exact negatives
for missing chain, missing local snapshot, unavailable source candidate, and
tampered historical content.
