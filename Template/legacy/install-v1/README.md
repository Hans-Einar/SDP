# Retained install-v1 templates

This archive preserves the project-root and seven-phase sdp-root payloads used by
the legacy install-v1 contract. The folder version identifies that interface,
not a separate published SDP release. Archived template bytes are preserved by
the TS1 relocation; the current install-v1 inventory points here so its retained
historical contract can still be inspected. The old installer is retired. Do not extend these templates for new projects.

Current templates are in [Template/sdp-root](../../sdp-root/README.md).
Four neutral manifest/release/Traceability seeds have current copies there;
future changes to those copies need not change the archived payloads.
The legacy project-root instructions have no current Go-profile consumer.
