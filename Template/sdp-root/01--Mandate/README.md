# Mandate

Record the owner's desired outcome, project boundary, constraints and stakeholders.

Keep the owner mandate authoritative. A Mandate-study.md is optional when clarification or feasibility work is needed; distinguish owner decisions from agent assumptions. Link later requirements to this intent. Do not replace the mandate with a generated model summary.

Use this README as a project-specific index when content is added. Keep studies
with the phase they inform; numbered folders are not fixed abstraction levels.
See [the document guide](../SDP-DOCUMENT-GUIDE.md) and
[source organization](../SDL/README.md).
