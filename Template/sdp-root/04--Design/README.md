# Design

Explain detailed behavior, contracts, states and data responsibilities with their rationale.

Canonical model details belong under ../SDL/<System>/Containers/<Container>/ and system-owned Contracts, Shared and Scenarios. UI definitions belong in that System's SDUI/<UIContainer>/ folder. Optional report subfolders can mirror actual container ownership. Keep design plans and studies here; do not hide all concerns inside one architecture.design file.

Use this README as a project-specific index when content is added. Keep studies
with the phase they inform; numbered folders are not fixed abstraction levels.
See [the document guide](../SDP-DOCUMENT-GUIDE.md) and
[source organization](../SDL/README.md).
