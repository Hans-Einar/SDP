# Implementation

Keep selected implementation plans, milestone status and pointers to technical evidence.

Use the installed Planning skill to select phases, milestones, BranchPolicy and CommitPolicy proportionate to the work. Link source design, requirements and verification. Application code remains in its normal source tree, not in this process folder. Record lifecycle in ProjectManagement and design/code evidence in Traceability; completed management work alone does not establish feature implementation.

Use this README as a project-specific index when content is added. Keep studies
with the phase they inform; numbered folders are not fixed abstraction levels.
See [the document guide](../SDP-DOCUMENT-GUIDE.md) and
[source organization](../SDL/README.md).
