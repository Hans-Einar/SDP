# Requirements

Explain needs, actors, use cases, features and acceptance obligations.

Put machine-readable facts in ../SDL/<System>/ using supported SDL syntax, with one definition per concern. Keep user stories, rationale and unresolved questions here when they need prose. Actors may be people or external systems; do not assume every actor is a user. Link requirements to the mandate and selected model views.

Use this README as a project-specific index when content is added. Keep studies
with the phase they inform; numbered folders are not fixed abstraction levels.
See [the document guide](../SDP-DOCUMENT-GUIDE.md) and
[source organization](../SDL/README.md).
