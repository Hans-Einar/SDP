# Project SDP area

This project uses sdp-five-phase/0.1 with shared project management.
Read the installed facts in Framework/installed-toolkit.manifest.yaml.
Numbered folders express process responsibilities, not fixed abstraction levels.
Organize architecture and design by System and actual container responsibility.
Studies belong with their affected phase. Maintain documentation in English.

Use KanBan for proposals and active work; ProjectManagement/Ledger.ndjson owns
card, Scrum, Sprint, Maintenance, CodeReview and Refactor lifecycle events.
Traceability records system design/code changes and evidence with management
references. Prefix new traceability IDs with the affected System identity.
