# SDP project templates

This is the source of neutral project-owned templates. Managed payload lives in
Toolkit/payload; canonical skills live in Skills. Repository lifecycle records
under SDP are never installation seeds.

The current versioned process profile is in profiles/five-phase. Its authored
configuration is [five-phase.json](../Toolkit/profiles/five-phase.json); the
[process installation contract](../Toolkit/docs/Process-Installation.md) defines
build, reviewed plan, apply and forward recovery. It installs the five phase
homes, phase-local studies and shared project management. Systems/containers
organize source content; folders do not prescribe abstraction levels.

project-root and sdp-root retain the explicit install-v1 inventory and shared
neutral release/Traceability templates. Their seven-phase destinations apply
only to the legacy interface; they are not an alternative current project
recommendation. V2 migrations preserve/archive legacy sources instead of
silently splitting their semantic content.

MAINT-SDP-0003 implements the versioned successor to the earlier
[phase-profile proposal](../docs/process/Project-Phase-Profile-Proposal.md).
The built bundle is deterministic and contains no live cards, history or models.
