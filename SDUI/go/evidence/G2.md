# G2 — faktisk verifikasjon

## G2-M1

Go 1.27.1 på Linux. `go test ./layout` består. Testene måler geometri fra
parsede SDUI-kilder, inkludert Concept1 uten håndplasserte koordinater.
Fr-fordeling er prøvd med minimum, maksimum og metning; scale-overflow avvises.
16:9 breddebevarer høyde ved to viewports; for lav viewport blir ikke contain.
Font endres ikke ved resize. Header/body/footer, sirkulær størrelsesavhengighet,
klipp/trefftesting og eksplisitt avvisning av uimplementert scroll er prøvd.

Dette er målebevis. SVG, native Fyne-interaksjon og Markdown-provider har egne
etterfølgende milepæler og er ikke bevist av disse testene.

## G2-M2

`go test -race ./...` består. SVG-tester kontrollerer XML, escaping, geometriske
primitiver og byteidentisk gjentatt eksport. CLI eksporterer Concept1 via
`--format svg --entry bucking --width 1920 --height 1200` til
`concept1-layout.svg`. `rsvg-convert` rendret denne til PNG; bildet er visuelt
kontrollert med seks bokser, riktige 1:1 og 25:50:25 bredder, 15:45:40 radhøyder,
knapper i header og footer nederst. Kontrollen avdekket manglende vertikal
stretch; dette er rettet i layoutmotoren og dekket av geometrisk regresjonsprøve.

Teksten eksporteres som konturer fra den samme innbakte fonten som målingen;
SVG-titler beholder literalene for tilgjengelighet. Ingen systemfont kreves.
Markdown vises fortsatt som rå tekst i dette M2-beviset; provider følger M4.
