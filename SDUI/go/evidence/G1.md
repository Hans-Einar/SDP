# G1 — frontendport

## G1-M1

Go 1.27.1, Linux amd64. `go test ./...` består. Parserens JSON-AST sammenlignes
strukturelt med alle lagrede eksempel-AST-er, inkludert Concept1 og symbolske
bindinger. Kildeposisjoner for UTF-8/CRLF, negative profil-/lexerprøver,
ressursgrenser og alle trunkeringer av en liten kilde kontrolleres.
Fuzz-seedene kjøres også som ordinære tester. Ingen fuzz-kampanje er hevdet.

CLI leverer syntax-only AST. G1-M2 semantikk/normalisering og G1-M3 eksporter
gjenstår. Ingen SDL-runtime eller GUI er bevist av disse testene.

## G1-M2

Lokal validering og normalisering er portert. 93 tilfeller fra de eksisterende
Python-testene/eksemplene er fanget med `tools/capture_port_cases.py` (kjør fra
repoets rot) og sjekkes av Go uten Python. Positive tilfeller sammenligner hele
instansstrukturen, argumenter, normalisert layout og kildeposisjoner; negative
prøver krever samme feilkode. Selvstendige tester sjekker at gjenbrukte instanser
ikke deler muterbar layout, heller ikke ratio-/padding-arrays med AST-en.
`go test ./...` består. CLI validerer lokal profil som standard; --syntax-only er
et eksplisitt valg. Ingen ref-fil åpnes, og eksterne SDL-symboler blir ikke validert.
