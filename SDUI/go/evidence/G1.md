# G1 — frontend port

Historical milestone observations; translation is not a new test run.

## G1-M1

Go 1.27.1, Linux amd64. `go test ./...` passed. Parser JSON ASTs were compared
structurally with all stored examples, including Concept1 and symbolic bindings.
Tests cover UTF-8/CRLF positions, negative profile/lexer cases, resource limits and
every truncation of a small source. Fuzz seeds run as ordinary tests; no fuzz
campaign is claimed. The CLI provides syntax-only AST. M2 semantics/normalization
and M3 exports remained; these tests prove neither SDL runtime nor GUI behavior.

## G1-M2

Local validation/normalization was ported. 93 cases from Python tests/examples were
captured with `tools/capture_port_cases.py` from the repository root and checked by
Go without Python. Positive cases compare complete instance structure, arguments,
normalized layout and positions; negative cases require matching diagnostic codes.
Independent tests verify reused instances do not share mutable layout, including
ratio/padding arrays with the AST. Tests passed. The CLI validates the local profile
by default; --syntax-only is explicit. No ref file opens or external SDL symbol is
validated.

## G1-M3

Concept1 console/Markdown matched snapshots byte-for-byte. CLI tests cover formats,
errors without partial stdout, explicit entry and source overwrite protection.
SVG/HTML control galleries share normalized instances; tests cover visibility,
inherited enabled, escaping and absent callbacks. Rendered controls.svg was checked
visually: buttons, disabled controls and input values. This was still a gallery;
G2 replaces it and old hand-positioned prototypes with general Concept1 geometry.

All three packages passed `go test ./...` and final `go test -race ./...`.
Unicode cell width uses x/text 0.42.0, requiring Go 1.26; verification used 1.27.1.
Python remained the port oracle until G5-M4 and had no role in the Go CLI.
