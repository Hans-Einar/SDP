# G1 — frontendport

## G1-M1

Go 1.27.1, Linux amd64. `go test ./...` består. Parserens JSON-AST sammenlignes
strukturelt med alle lagrede eksempel-AST-er, inkludert Concept1 og symbolske
bindinger. Kildeposisjoner for UTF-8/CRLF, negative profil-/lexerprøver,
ressursgrenser og alle trunkeringer av en liten kilde kontrolleres.
Fuzz-seedene kjøres også som ordinære tester. Ingen fuzz-kampanje er hevdet.

CLI leverer syntax-only AST. G1-M2 semantikk/normalisering og G1-M3 eksporter
gjenstår. Ingen SDL-runtime eller GUI er bevist av disse testene.
