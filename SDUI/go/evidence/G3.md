# G3 — faktisk verifikasjon

## G3-M1

Typede Go-handles har session, offentlig widgetbane, generasjon og widgettype.
Midlertidige `$`-grupper påvirker ikke offentlig identitet for navngitte widgets.
Events har modellrevisjon og monoton sekvens; input-commit har draftrevisjon.
Runtime er synkron og eid av én UI-goroutine. Den importerer verken Fyne eller SDL.

`go test ./runtime` består: ubundet handling, duplikat/stale event, teardown,
callback→property-batch, atomisk avvisning av ugyldig batch, dirty-draft-konflikt,
eksplisitt draft-aksept og uavhengig snapshot. Ingen rendering eller reload
kjører callback. Hot reload og native adapter følger M2/M3.

## G3-M2

`go test -race ./runtime ./reload` består. En ekte midlertidig fil blir overvåket:
ugyldig mellomlagring gir diagnose uten å endre widget, modellrevisjon eller
siste gyldige kildehash; atomic rename til gyldig kilde publiserer ny etikett;
sent, eldre resultat avvises; kansellering avslutter watcher.

Watcheren leser begrenset kilde og sammenligner SHA-256 før ny parse/validering.
Den håndterer samme filstørrelse og editorens atomic rename. Kanalen beholder
bare nyeste kandidat. Publisering skjer eksplisitt hos eieren; watcher-goroutinen
muterer aldri session eller native widgets. Valgfri målevalidator kan avvise en
kandidat før publisering. Native tilkobling og bevaring ved reload prøves i M3.

## G3-M3

`go test -race ./...` og desktop-bygg består. Runtime- og adapterprøver bevarer
navngitt input gjennom nye anonyme grupper/rader: handle, akseptert verdi,
dirty draft og fokus består, mens ny etikett brukes. Defaults initialiserer
bare nye instanser. Typebytte/sletting gir ny generasjon; endret callbackbinding
beholder ikke gammel handler. Gamle modell-events og native OnSubmitted-kall
avvises. Enter committer én gang; Escape gjenoppretter verdi uten callback.
Programmatisk oppdatering gir ingen ny draft-/domenehendelse. Ugyldig målt layout
avvises før sessionpublisering, med samme levende native kontroll beholdt.

Den native `host/fynehost/cmd/reloadsmoke` er bygget med desktop-tag og kjørt med
OpenGL på Xvfb :93. Den redigerer en virkelig kildefil mens vinduet kjører:
ugyldig kilde → beholdt modellrevisjon 1 → atomic rename → revisjon 2. Input
`draft12` og fokus består; gammelt native callback avvises; ny commit gir
nøyaktig én registrert Go-callback. Resultatet er også visuelt kontrollert i
`native-reload.png`, tatt fra X11 mens vinduet viser den nye overskriften.
Dette er kjørbar SDUI-hot-reload. Ingen SDL-runtime eller dynamisk omlasting av
kompilert Go-maskinkode er påstått.
