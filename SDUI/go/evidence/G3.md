# G3 — verification evidence

Historical milestone observations; translation is not a new test run.

## G3-M1

Typed Go handles contain session, public widget path, generation and widget type.
Temporary `$` groups do not affect named widget identity. Events carry model revision
and monotonic sequence; input commits carry draft revision. Runtime is synchronous,
owned by one UI goroutine, and imports neither Fyne nor SDL.

Runtime tests passed: unbound action, duplicate/stale event, teardown, callback to
property batch, atomic invalid-batch rejection, dirty-draft conflict, explicit draft
acceptance and independent snapshot. Rendering/reload never invokes callbacks.
Hot reload and native integration follow M2/M3.

## G3-M2

Runtime/reload race tests passed. A real temporary file was watched: invalid saves
produce diagnostics without changing widgets, revision or last valid source hash;
atomic rename to valid source publishes a new label; late older results are rejected;
cancellation stops the watcher.

The bounded watcher compares SHA-256 before parse/validation, supporting equal file
sizes and editor atomic rename. Its channel retains only the newest candidate.
Publication is explicit at the owner; the watcher never mutates sessions/native
widgets. Optional measurement validation can reject candidates before publication.
Native integration and state preservation follow M3.

## G3-M3

Full race tests and desktop build passed. Runtime/adapter tests preserve named input
through new anonymous groups/rows: handle, accepted value, dirty draft and focus remain
while labels change. Defaults initialize new instances only. Type changes/deletion
create a new generation; changed callback bindings do not retain old handlers. Old
model events and native OnSubmitted calls are rejected. Enter commits once; Escape
restores without callback. Programmatic updates generate no new draft/domain event.
Invalid measured layout is rejected before publication, retaining the native control.

The desktop-tagged host/fynehost/cmd/reloadsmoke ran with OpenGL/Xvfb :93, editing a
real source while its window ran: invalid source → retained revision 1 → atomic rename
→ revision 2. Input draft12 and focus survived; old native callbacks were rejected;
a new commit invoked exactly one registered Go callback. native-reload.png was
visually checked while the new heading appeared. This proves SDUI hot reload, not
SDL runtime or dynamic loading of compiled Go machine code.
