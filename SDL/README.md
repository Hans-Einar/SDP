# SDL — ny prosjektdokumentasjon

[SDLs KanBan](SDP/Agents/KanBan/README.md) registrerer språkforslag og lokale
konsekvenser av SDP-verktøy/prosess. Denne katalogen etablerer bare prosjektets
SDP-dokumentinngang. Implementasjon, aktive profiler og eksisterende dokumentasjon
ligger fortsatt i [SystemDesignLanguage](../SystemDesignLanguage/README.md).

Ingen kildekode er flyttet eller duplisert, og eget GitHub-repo er ikke opprettet.
Repo-utskilling og lenke-/modulmigrering må planlegges før gjennomføring.
