# G7 — launching source-based documentation browsing

## G7-M1

At this milestone the launcher was `SystemDesignLanguage/scripts/sdl-design` (now
`SDL/scripts/sdl-design`). It uses prebuilt SDL CLI, navigation-enabled XFMD and the
existing Mermaid renderer. Startup performs no Go compilation, daemon launch or full
static export. It opens the main page and sidebar navigator. Each detail click rereads
source. Navigation generates 14 overview pages plus manifest, no detailed Mermaid/SVG;
its inventory refreshes at the next launch.

The native probe used isolated HOME/runtime and Xvfb :93. It launched through a symlink
from another directory; real XFMD IPC reported the correct main page/navigation. The
registered prebuilt SDL tool generated a real selected SVG. WM_DELETE_WINDOW closed
the host and removed temporary files. Missing SDL produced a precise error without
leftovers; a fake go first in PATH proved no compiler invocation.

Reproduction: `tools/verify_design_launcher.py --launcher PROGRAM --xfmd XFMD --sdl SDL
--renderer MMDR`. The test starts Xvfb :93; avoid an occupied display. `bash -n` and
`git diff --check` passed. No Go core code changed.

The prebuilt binary was installed in `.local/lib/sdp/sdl`; `.local/bin/sdl-design`
links to the versioned launcher. Compilation occurred once during setup, not in the
launcher. Existing installed XFMD and user windows were unchanged. These are the
original milestone observations, translated without rerunning the native probe.
