## G6-M4

The Linux service uses private Unix SOCK_SEQPACKET, same UID, 32 KiB messages,
16 connections and four concurrent projections. Cache keys include source hash,
projector version, renderer fingerprint and canonical selection. The whole source
is a dependency in this import-free profile. Source changes during rendering or
newer requests prevent stale opening.

Store owns an exclusive process lock, atomic index, immutable packages, persistent
leases and request sequences. Restart reuses leased packages and removes unpublished
remnants. Defaults: 128 MiB/64 packages, 1024 leases, 1024 client/window/panel tracks.
Unleased packages may be evicted; time alone never removes leased ones. Uncertain
open acknowledgement conservatively retains a lease.

Broker/reader race tests passed: cache/invalidation, quotas, two leases, release,
restart, stale/rapid clicks, source changes, IPC and cleanup. Native automation with
real daemon/mmdr/FOX verified SIGKILL/restart retains SVG/sequence, invalid SDL retains
the view, replacement releases the old document and WM_DELETE_WINDOW releases the last
lease. `broker-native.png` was checked. XFMD phase 050: 5fa35e3 + 47a245a; affected native
CTests passed. Runtime files must not be assumed RAM-backed.
